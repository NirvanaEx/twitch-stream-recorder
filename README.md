# TSR: быстрый фоновый автоподгон звука и чата записи

Выложено 23.09.2026 на stream.neyron.site отдельным сервисом **tsr-sync**, версия `f64d0b66918b`. API и текущая запись не перезапускались. Эта версия заменяет первоначальную доработку измерения во время воспроизведения.

## Поведение

- Короткий фрагмент оригинальной аудиодорожки Twitch загружается отдельно. FFmpeg декодирует его и участок записи быстрее реального времени. Анализ не использует звук браузера, captureStream, громкость или перемотку плеера.
- Сравниваются изменения спектра в 16 частотных полосах. Совпадение должно быть сильным, единственным и независимо подтверждаться обеими половинами 12-секундного образца. Неоднозначные результаты не сдвигают аудио.
- Поиск сначала охватывает ±12 секунд от предполагаемой позиции, затем расширяется до ±120 секунд. Вместо прежнего предела общего сдвига в 60 секунд проверяются границы записи.
- Проверка повторяется через 15 секунд после результата, после перемотки и смены дорожки. Результаты участков хранятся отдельно; ближайшее измерение применяется в пределах 30 секунд. Это локальные измерения, а не точное знание момента переключения дилея.
- Сопоставление работает и на паузе. Браузер может ограничивать таймеры фоновой вкладки; уже отправленный расчёт выполняется на сервере.
- Автоподгон учитывает только **чат записи со stream.neyron.site**, как попросил пользователь. Оригинальный чат Twitch не меняется.
- Чат получает отдельную автоматическую поправку из проверенных часов записи либо PROGRAM-DATE-TIME сегментов VOD. Числовой сдвиг аудио не копируется в чат. Ручная поправка добавляется к автоматической.
- Сравнение спектров выполняется в Worker. Одновременно разрешён один расчёт; одинаковые запросы объединяются, результаты кэшируются. Основной цикл API остаётся свободным.

## Изменения и выкладка

Новый маршрут API: `GET /api/public/streams/:id/audio-sync?vod=...&position=...&estimate=...`.
Исходники сравнения: `apps/api/src/modules/public/{background-audio-sync,audio-fingerprint,audio-sync.worker,twitch-sync-source}.ts`.
Клиент: `apps/web/app/lib/twitch-audio-script.ts`. Тесты: `audio-sync.spec.ts` и `apps/web/scripts/test-twitch-audio.cjs`.

Новых пакетов и миграций базы не требуется. Обработчик и web-payload обслуживает отдельный контейнер `tsr-sync`, созданный на основе текущего образа API с FFmpeg/Prisma. Подключены два маршрута Nginx через плавную перечитку конфигурации. Текущий загрузчик TSR получает свежий payload при обновлении или следующем открытии Twitch; переустановка не требуется.

При отсутствии доступного оригинала или уникального совпадения аудиосдвиг остаётся прежним. Если доступен сегментный календарный час, чат может корректироваться отдельно. При ошибке начального предположения больше двух минут может понадобиться ручное приближение.

Проверка в пользовательском браузере на известном переключении дилея ещё нужна. Клиент проверен в VM, сервер — на реальном аудио.

Основа сохранена в `baseline.tar.gz` и `api-baseline.tar.gz`. Исходный SHA-256 `twitch-audio-script.ts`: `bb3da0bfa4c8d0f3910bb542d55ed7882a8047a3a4790213d1fe1719a8f5bb37`.
