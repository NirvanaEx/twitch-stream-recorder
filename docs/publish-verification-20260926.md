# Проверка исходников перед публикацией в GitHub

Проверялся объединённый checkout `/root/projects/twitch-stream-recorder-current`.
Рабочие контейнеры не перезапускались. Тесты выполнялись в изолированных
контейнерах без сети, рабочей БД и каталога записей. Для web сначала установлены
зависимости из имеющегося package-lock; lock-файл не менялся.

- API: полная компиляция TypeScript и 207 тестов — успешно.
- Web: 44 теста — успешно; проверки предзагрузки превью, переключения источников,
  возобновления просмотра и готового виджета Twitch — успешно.
- Производственная сборка Next.js и проверка типов worker — успешно.
- Синхронизация: 13 клиентских, 13 серверных/origin и 2 проверки готовых payload — успешно.
- Отдельные аудио и retention: 12 тестов — успешно, включая реальную обработку
  локального тестового аудио через FFmpeg без доступа к рабочим данным.
- Compose с `.env.example`, синтаксис Python/shell, Git diff и поиск секретов — успешно.

В старом вспомогательном UI-тесте переключатель источника передавался через
удалённое свойство `VideoPlayer.sourceControl`. Тест приведён к действующей
структуре страницы: переключатель располагается рядом с плеером в панели.
Поведение приложения при публикации не менялось; обновлён также генерируемый
виджет из текущих исходников и зафиксированных зависимостей.

Подробные журналы оставлены в локальном `verification/` вне Git.
Архивная ветка хранит прежние незакоммиченные правки для восстановления,
не предназначена для выкладки и не входит в результаты тестов выше.
